# Bot Manzanita 1.15.0

## Expresiones y catálogo

- Añadido repertorio de 25 acciones anime SFW: felicidad, té, abrazos, caricias, golpes de caricatura, baile, saludo y otras.
- Los comandos `a!happy`, `a!sip`, `a!slap @persona` y los demás publican un GIF elegido al azar y un texto contextual de Manzanita.
- Se usa la API v2 de NEKOS.BEST con User-Agent identificable, validación del host del GIF, timeout, cooldown individual y límite de frecuencia por categoría.
- Añadido `/catalogo`, `a!catalog` y `a!help`, con panel Components V2 y selector de categorías para utilidades, expresiones, música, economía, RPG y administración.
